Дневник здоровья в виде календаря и список дел. Данные хранятся в приватном репозитории KryukovMikhail/notes.

  1. Если репозитория ещё нет — создайте приватный репозиторий notes (можно пустой).
  2. Откройте создание fine-grained токена.
  3. Repository access → Only select repositories → notes.
  4. Permissions → Repository → Contents: Read and write.
  5. Скопируйте токен и вставьте ниже.
