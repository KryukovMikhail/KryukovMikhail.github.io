Вход

Текст книги и записи голоса хранятся в вашем приватном репозитории на GitHub. Сайт открывает их по токену.

  1. Репозиторий с книгой — ваш приватный diary. Он может быть пустым.
  2. Создайте токен: Fine-grained token → Repository access: Only select repositories → выберите этот репозиторий → Permissions → Contents: Read and write.
  3. Вставьте имя репозитория и токен ниже.

Токен хранится только в браузере этого устройства и отправляется только в GitHub. На чужом компьютере снимите галочку «Запомнить».

Подсказки

Команды голосом: точка запятая вопросительный знак восклицательный знак двоеточие тире многоточие открыть кавычки / закрыть кавычки новый абзац. Если мешают (например, «точка зрения»), выключите галочку выше.

Где работает лучше всего: Chrome или Edge на компьютере, Chrome на Android. На iPhone — Safari. Распознаванию нужен интернет. Аудио пишется и без него.

Как рассказывать: один фрагмент — один эпизод. Говорите как другу, причешете потом в разделе «Текст». Кнопка микрофона ставит запись на паузу, повторное нажатие продолжает.

Где хранится: после сохранения фрагмент уходит в ваш репозиторий на GitHub (индикатор справа вверху). Если интернета нет, он подождёт на устройстве и отправится сам, когда связь появится.
